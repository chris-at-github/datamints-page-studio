# Sora

CI-Schrift für die Oberfläche von Page Studio (Startseite und Overlay), übernommen aus dem Abzug von auftrags-sonar.de.
Sora steht unter der SIL Open Font License 1.1 (https://openfontlicense.org), Quelle: https://github.com/sora-xor/sora-font.
Der Server liefert die Dateien unter `/__dps/fonts/`, das Overlay registriert sie als Familie `dps-sora`, damit sie nicht mit Schriften der Seite kollidiert.
